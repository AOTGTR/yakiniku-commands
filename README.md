# YL Yakiniku — commands

Gift commands for the TikTok live game **YL Yakiniku** (YLTik / TikConnector).

**Page:** https://aotgtr.github.io/yakiniku-commands/

Each command is a word with an optional number (`set 6`, `tongs 5`, `staff 16`, `random prank 1 10`). Copy it into a gift rule's command field.
